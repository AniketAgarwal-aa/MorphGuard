# Experiments and results

No supervised model metrics are reported yet. This is intentional: the repository has verified MONOT attack counts and ONOT subset metadata, but not a locally encoded identity-safe, reviewed binary label manifest. The permitted next experiment is the restricted source-confounded protocol documented in `SCIENTIFIC_VALIDITY_AND_LABEL_PROTOCOL.md`.

Completed exploratory results are dataset facts only: 46,792 valid PNG records, 24,140 MONOT and 22,652 ONOT; ONOT digital and print-scan each contain 11,326 records; all full-audit records decoded successfully.
