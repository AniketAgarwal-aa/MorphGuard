# MONOT Ground-Truth Review

The local MONOT package contains Gate_10, Gate_25 and Morphed folders, plus no image-level CSV/XLSX/JSON/XML ground-truth manifest. Morphed filenames encode candidate source identities and generation parameters; this is provenance evidence, not a reviewer-approved label. Gate categories describe acquisition/generation strata and are not binary classes. Official context: [MONOT documentation](https://miatbiolab.csr.unibo.it/monot-synthetic-dataset/). Human review remains required for class approval and pair verification.
