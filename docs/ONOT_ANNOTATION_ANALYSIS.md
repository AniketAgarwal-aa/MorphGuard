# ONOT Annotation Analysis

ONOT contains 11,326 digital and 11,326 print-scan records. Subject folders and filename conventions expose subject-style identifiers and acquisition variants. The three threshold text files list image subsets at cosine thresholds; they describe similarity/identity variability strata, not class labels.

No local image-level file was found that marks each image as bona fide or morphed, and no morph-pair manifest was found. ONOT therefore supplies acquisition and subset evidence only. It must not be auto-labelled genuine merely because it is ONOT.

Readiness: restricted acquisition/quality/identity analyses and candidate bona-fide review; supervised use requires explicit human verification and provenance.
